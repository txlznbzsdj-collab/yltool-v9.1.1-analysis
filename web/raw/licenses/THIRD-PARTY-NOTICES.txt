THIRD-PARTY NOTICES
===================

YouLong ("游龙编程") is a modified distribution of the Acode code editor.

This file lists the third-party open source components that this application
redistributes, together with the license each one is distributed under.
Every entry below was verified against the license file or the `license`
field shipped inside the installed package, except where the entry itself
says otherwise. Every JavaScript dependency that was removed from the build
while this file was being revised says so in place; conversely, the three
cases that needed special handling are documented explicitly rather than
dropped: `@emmetio/codemirror6-plugin` was removed from the build because it
granted no license at all, and the remaining cases are written out in
sections 4 and 4b together with the exact declarations found on disk. No
statement here is inferred from a component's name or group.

The full license text of each component is shipped alongside this file, as
`licenses/components/<name>.txt` for JavaScript dependencies and
`licenses/components/plugins/<name>__LICENSE` (or `__NOTICE`) for Cordova
plugins. Those files were copied out of `node_modules/` and the plugin
directories at build time and are redistributed with the app; the texts are
therefore NOT duplicated inside this file. See section 5.

redistributes compiled Java/Kotlin code in addition to the JavaScript in

build-time-only `node_modules/` JavaScript tree, which is never read at
runtime.

artifact itself; no license is inferred from the group or artifact name.
