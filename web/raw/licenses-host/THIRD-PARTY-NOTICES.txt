THIRD-PARTY NOTICES - YouLongTool host application
==================================================

This file covers the part of the installed application that is NOT the Acode-
derived editor. The package com.youlong.tool ("游龙工具") contains two bodies of
third-party code, and they are documented in two separate files that travel
together inside this APK:

  assets/www/licenses-host/THIRD-PARTY-NOTICES.txt   this file - the host app
  assets/www/licenses/THIRD-PARTY-NOTICES.txt    the Acode-derived 游龙编程
                                                 editor module and its own
                                                 JavaScript / Cordova / Maven
                                                 dependencies

The whole APK is one distributed work; the two files together are its complete
attribution. Neither file alone is complete on its own.

Why this file sits under `www/`: the host application encrypts its own
`assets/` tree at build time (AES-256-GCM, key bound to the signing
certificate; filenames are also rewritten). A notice stored there would reach
the recipient only as ciphertext, which is not a notice. This location is
outside that encrypted tree, so the text below is readable by anyone who
opens the APK. That is deliberate, not an accident of layout.

Provenance: the Maven coordinates below were taken from the Android Gradle
Plugin's own SDK dependency report for the release build
(`app/outputs/sdk-dependencies/release/sdkDependencies.txt`), which lists all
135 Maven libraries present in this APK. The coordinates already documented in
the Acode module's notices were subtracted, leaving the 101 listed here. For
each remaining coordinate the license name was read from that exact artifact's
own POM in the Gradle module cache, walking up the POM <parent> chain when the
artifact POM declared no <licenses> element; no license was inferred from the
group or artifact name. All 101 resolved.
